# KALINGA System

## Overview

KALINGA is a healthcare management and healthcare facility navigation system designed to improve accessibility, communication, and healthcare service management. The system allows users to search healthcare facilities, manage appointments, view healthcare services, and interact with healthcare providers through a centralized platform.

The system also includes administrative tools for managing healthcare provider applications and monitoring healthcare-related activities.

---

# Features

## User Features

* Search healthcare facilities using keywords or location
* Interactive map integration for healthcare facility navigation
* View healthcare facility information and available services
* Book and manage appointments
* View announcements and healthcare-related updates
* Submit reviews and feedback

## Healthcare Provider Features

* Manage healthcare facility profile information
* Update available healthcare services
* View and manage appointments
* Post announcements and healthcare updates
* Monitor patient requests and schedules

## Doctor Features

* Accept or reject appointment requests
* Manage patient appointments
* Create and edit prescriptions
* Monitor schedules efficiently

## Admin Features

* Approve healthcare provider applications
* Decline healthcare provider applications
* Suspend healthcare provider accounts with violations
* Manage healthcare facility information
* Monitor system activities

# Installation Guide

## Clone the Repository

```bash
git clone https://github.com/your-username/kalinga-system.git
```

## Navigate to Project Folder

```bash
cd kalinga-system
```

## Install Dependencies

```bash
npm install
```

## Run the Development Server

```bash
npm run dev
```
